O Claude agora também aprova o código

A Anthropic lançou na segunda (23) o Claude Ship, um trio de agentes para a fase depois do código escrito. O Code Review revisa os pull requests, os pedidos para juntar código novo ao projeto. O PR Steward conserta testes quebrados e conflitos e explica como desfazer cada mudança.

A novidade é o Claude Approvals: ele aprova sozinho mudanças de rotina, seguindo uma política que a equipe escreve em linguagem comum. Vale para os planos Team e Enterprise, no GitHub.

Com cautela

Os dois agentes novos estão em teste. A Anthropic sugere ligar a aprovação primeiro só no modo observação, num único repositório e com teto de gasto mensal.
